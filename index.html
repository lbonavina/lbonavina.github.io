Dicas Nova York

Blog de viagem · SEO · Performance · WordPress

Desafio

  • Desenvolver tema performático e componentizado em nicho competitivo de viagens
  • Migrar infraestrutura com zero downtime, preservando SEO e indexação existentes
  • Atingir 90+ no Lighthouse em mobile — ambiente mais restritivo que desktop
  • Aplicar SEO técnico completo para competir com portais de grande porte no Google

Solução Implementada

  • Tema customizado com Sage 10 + Tailwind CSS — código limpo, componentizado e sem CSS não utilizado
  • Migração de infraestrutura para Cloudways com configuração de servidor, DNS, SSL e cache de servidor
  • Otimização de performance: lazy loading, minificação de assets, compressão de imagens e estratégia de cache avançada
  • SEO técnico: schema markup, Core Web Vitals, estrutura de URLs canônicas, sitemap e otimização de indexação
